# Security policy

Turnierplan.eu – Embed tournaments is licensed under GPL-2.0-or-later.

Please report security vulnerabilities privately to **info@pixel33.eu**. Include the affected plugin version, WordPress and PHP versions, reproduction steps, impact, and any suggested mitigation.

Do not publish exploitable details, credentials, private tournament data, or personal data in a public GitHub issue. Ordinary bugs and feature requests belong in the [public issue tracker](https://github.com/pixel33-eu/turnierplan_eu/issues).

Security fixes are prepared in the public source repository after affected users can update safely. WordPress.org releases use the version declared in VERSION, the main plugin header, readme.txt, package.json, and blocks/embed/block.json.
